UNIT 2 – Fundamental of Prompt Writing

Topic 1: Structure of a Prompt – Role, Task, Context, Constraints, and Output Format

⸻

Learning Objectives

After completing this topic, students will be able to:

* Explain the anatomy of an effective prompt.
* Identify the major components of a prompt.
* Understand the purpose of Role, Task, Context, Constraints, and Output Format.
* Construct structured prompts using the RTCCO framework.
* Improve vague prompts by adding relevant information.
* Understand when every component is necessary and when it is not.
* Evaluate whether a prompt contains enough information to produce a useful response.

⸻

1. Introduction

In the previous unit, we learned that:

Prompt Engineering is the skill of communicating effectively with AI.

Now we need to answer an important question:

What should a good prompt actually contain?

A prompt is not simply a question.

A well-designed prompt provides the AI with enough information to understand:

Who should you act as?
        ↓
What should you do?
        ↓
What information should you use?
        ↓
What rules should you follow?
        ↓
How should the answer be presented?

This gives us a simple framework:

RTCCO

R → Role
T → Task
C → Context
C → Constraints
O → Output Format

RTCCO is a teaching framework for designing structured prompts. It is not a requirement that every prompt must contain all five components.

3. Component 1 – ROLE

What is a Role?

The Role tells the AI what perspective, expertise, or function it should adopt while completing the task.

Examples:

Act as a Computer Science professor.

Act as a Python developer.

Act as a career counselor.

Act as a technical interviewer.

Act as a marketing copywriter.

⸻

Why Use a Role?

A role can help establish the desired perspective and style.

Compare:

Without Role

Explain database normalization.

With Role

Act as a database professor and explain database normalization to second-year Computer Science students.

The second prompt provides more context about the intended perspective and audience.

⸻

Important Note About Roles

Students should understand something important:

A role does not magically give the AI real-world credentials or expertise.

If we write:

“You are the world’s greatest doctor.”

the AI does not actually become a doctor.

A role is primarily an instruction about how the response should be framed.

Therefore:

Role ≠ Real-world qualification

⸻

4. Component 2 – TASK

What is a Task?

The Task tells the AI exactly what you want it to do.

This is usually the most important part of the prompt.

Examples:

* Explain
* Summarize
* Compare
* Generate
* Analyze
* Translate
* Classify
* Rewrite
* Debug
* Create
* Evaluate

⸻

Weak Task

AI and education.

This does not specify an action.

⸻

Strong Task

Explain how Generative AI can improve student learning.

Now the AI knows what to do.

⸻

Use Action Verbs

Good prompts often contain clear action verbs.

Weak	Strong
AI	Explain AI
Java	Teach Java OOP
Resume	Review my resume
Data	Analyze this dataset
Email	Rewrite this email professionally
Code	Debug the following C++ code

⸻

5. Component 3 – CONTEXT

What is Context?

Context provides the background information the AI needs to perform the task appropriately.

Context can include:

* Target audience
* Subject
* Background
* Existing information
* Purpose
* Situation
* Experience level

⸻

Example

Without context:

Explain recursion.

With context:

Explain recursion to first-year engineering students who understand loops but have not studied recursion yet.

The second prompt gives the AI useful information about the learner.

⸻

Context Analogy

Imagine asking a teacher:

“Explain this.”

The teacher might ask:

“Explain what?”

Now imagine saying:

“I’m a first-year Computer Science student. I understand loops and functions but I’m struggling to understand recursion. Please explain it using a simple analogy.”

Now the teacher understands your situation.

Context gives AI the missing background.

⸻

6. Component 4 – CONSTRAINTS

What are Constraints?

Constraints are rules or limitations that tell the AI what it should or should not do.

Examples:

* Maximum word count
* Language
* Difficulty level
* Number of examples
* Topics to include
* Topics to avoid
* Tone
* Time period
* Technology version

⸻

Examples

Keep the answer below 300 words.

Use simple English.

Provide exactly five examples.

Do not use advanced mathematical notation.

Use C++17.

Explain the topic at a beginner level.

⸻

Why Constraints Matter

Consider:

Write an article about Artificial Intelligence.

The AI has enormous freedom.

Now:

Write a 500-word article about Artificial Intelligence for first-year engineering students. Use simple English, include three real-world examples, and avoid highly technical terminology.

The output becomes much more controlled.

⸻

7. Component 5 – OUTPUT FORMAT

What is Output Format?

Output Format tells the AI how the response should be structured or presented.

Examples:

* Bullet points
* Table
* Markdown
* JSON
* Numbered list
* Step-by-step explanation
* Email
* Report
* Code
* FAQ

⸻

Example

Without output format:

Compare Java and C++.

The AI chooses its own structure.

⸻

With output format:

Compare Java and C++ using a markdown table with columns for memory management, inheritance, pointers, platform dependency, and exception handling.

Now the structure is explicit.

⸻

8. Complete RTCCO Example

Let’s build a prompt step by step.

⸻

Step 1 – Task Only

Explain Binary Search.

Good starting point, but vague.

⸻

Step 2 – Add Role

Act as a Data Structures professor. Explain Binary Search.

Better.

⸻

Step 3 – Add Context

Act as a Data Structures professor. Explain Binary Search to first-year Computer Science students who understand arrays and linear search but are new to divide-and-conquer algorithms.

Better.

⸻

Step 4 – Add Constraints

Act as a Data Structures professor. Explain Binary Search to first-year Computer Science students who understand arrays and linear search but are new to divide-and-conquer algorithms. Use simple language and include one worked example.

Better.

⸻

Step 5 – Add Output Format

Act as a Data Structures professor. Explain Binary Search to first-year Computer Science students who understand arrays and linear search but are new to divide-and-conquer algorithms. Use simple language and include one worked example. Structure the answer with headings, a step-by-step algorithm, C++ code, time complexity, and a short revision section.

This is a much more structured prompt.

9. Complete RTCCO Template

Students can use this template:

ROLE:
Act as a [role/expert perspective].
TASK:
[Clearly describe what you want the AI to do.]
CONTEXT:
[Provide relevant background information, audience, purpose,
existing information, or situation.]
CONSTRAINTS:
[Specify rules, limitations, length, language, level,
number of examples, things to include/avoid, etc.]
OUTPUT FORMAT:
[Specify how the response should be structured.]

11. Example – Creating Study Notes

Poor Prompt

Make notes on Operating Systems.

⸻

RTCCO Prompt

Act as a university Computer Science professor.
Task:
Create study notes on Process Management in Operating Systems.
Context:
The notes are for second-year engineering students who
understand basic operating-system concepts but are new to
process scheduling.
Constraints:
- Use simple and technically accurate language.
- Include real-world examples.
- Explain difficult terminology.
- Include important exam points.
- Keep the notes approximately 1,500 words.
Output Format:
Use Markdown with:
1. Learning Objectives
2. Introduction
3. Key Concepts
4. Examples
5. Comparison Table
6. Important Exam Questions
7. Quick Revision
8. Summary

⸻

12. Example – Email Writing

Role:
Act as a professional communication assistant.
Task:
Write an email requesting an extension for an assignment.
Context:
The student has completed most of the assignment but needs
two additional days to finish testing the implementation.
Constraints:
- Be polite and professional.
- Do not exaggerate the situation.
- Keep the email below 150 words.
Output Format:
Provide a complete email with a suitable subject line,
greeting, body, and closing.

⸻

13. Example – Resume Improvement

Role:
Act as a technical recruiter specializing in entry-level
software engineering positions.
Task:
Review and improve my resume.
Context:
I am a final-year Computer Science student applying for
software development internships.
Constraints:
- Do not invent qualifications or experience.
- Keep all factual information unchanged.
- Improve clarity and impact.
- Use professional language.
Output Format:
1. Major issues
2. Recommended changes
3. Improved resume content
4. Skills that could be highlighted

⸻

14. Example – Coding

Role:
Act as a senior C++ developer and programming instructor.
Task:
Write a C++ program to implement a Queue using a circular array.
Context:
The program is intended for undergraduate Data Structures
students learning arrays and queues.
Constraints:
- Use standard C++.
- Keep the implementation beginner-friendly.
- Include comments.
- Handle overflow and underflow.
- Do not use STL queue.
Output Format:
1. Approach
2. Algorithm
3. C++ Code
4. Sample Input/Output
5. Time Complexity
6. Explanation

⸻

15. Example – Travel Planning

Role:
Act as a travel planner.
Task:
Create a 4-day travel itinerary.
Context:
The travelers are two college students visiting Jaipur
for the first time.
Constraints:
- Moderate budget.
- Avoid an excessively packed schedule.
- Include approximate travel time between major locations.
- Include vegetarian food options.
Output Format:
Provide a day-wise markdown table with:
Time | Activity | Location | Estimated Cost | Notes

16. Role vs Context

Students often confuse these two.

Role

Who should the AI act as?

Act as a Python instructor.

Context

What background does the AI need?

The learner is a first-year student who knows basic Python but struggles with functions.

Together:

Act as a Python instructor. The learner is a first-year student who knows basic Python but struggles with functions.

⸻

17. Task vs Output Format

These are also different.

Task

What should AI do?

Create 10 MCQs about Data Structures.

Output Format

How should the result appear?

Present them in a table with Question, A, B, C, D, and Correct Answer columns.

Together:

Create 10 MCQs about Data Structures and present them in a markdown table with Question, A, B, C, D, and Correct Answer columns.

⸻

18. Constraints vs Output Format

Constraint

Controls the rules.

Use no more than 500 words.

Output Format

Controls the structure.

Use headings and bullet points.

Both can be used together.

⸻

19. Do We Always Need RTCCO?

No.

This is an important best practice.

A simple task may require only a short prompt.

For example:

Convert 5 kilometers to meters.

Adding:

Act as a mathematics professor…

would provide little benefit.

Therefore:

Use the amount of prompt structure required by the task.

⸻

20. Simple vs Complex Prompts

Simple Task

Translate "Good morning" into Hindi.

No need for a large prompt.

⸻

Moderate Task

Explain inheritance in Java for a beginner using
one real-world example and a simple code example.

Some context is useful.

⸻

Complex Task

Act as a senior software architect...
[Task]
[System requirements]
[Technical constraints]
[Expected architecture]
[Output structure]

More structure becomes valuable as task complexity increases.

⸻

21. Prompt Specificity

A useful principle:

More ambiguity
      ↓
More clarification needed
      ↓
More prompt detail

But this does not mean:

“Longer prompt = better prompt.”

Instead:

Relevant information = better prompt.

⸻

22. The Principle of Relevant Context

Compare:

Prompt A

Explain Binary Search. I am a student. My college is XYZ. My favorite color is blue. I had breakfast at 8 AM. I use an iPhone.

Most of this information is irrelevant.

⸻

Prompt B

Explain Binary Search to a first-year Computer Science student who understands arrays and linear search but is unfamiliar with divide-and-conquer algorithms.

Almost all information is relevant.

Lesson

Do not add information simply to make a prompt longer.

23. Prompt Quality Checklist

Before submitting a prompt, ask:

Role

* Did I specify a role if one is useful?

Task

* Is the task clear?
* Did I use an action verb?

Context

* Did I provide the information AI needs?

Constraints

* Are there important rules or limitations?

Output

* Did I specify the desired structure?

Verification

* Will I need to verify the output?

Classroom Activity 1 – Prompt Surgery

Give students this prompt:

“Write something about AI.”

Ask students to perform prompt surgery.

Step 1

Identify what is missing.

Role       ❌
Task       ⚠️
Context    ❌
Constraints ❌
Output     ❌

Step 2

Improve it.

Example:

Act as an AI educator. Explain how Generative AI is changing education for undergraduate students. Use simple language, provide five practical examples, and present the answer using headings and bullet points in approximately 600 words.

⸻

Classroom Activity 2 – RTCCO Challenge

Divide students into groups.

Give each group a scenario:

Group 1

Create study notes.

Group 2

Write a professional email.

Group 3

Generate C++ code.

Group 4

Plan a trip.

Group 5

Create a resume.

Each group must identify:

R → ?
T → ?
C → ?
C → ?
O → ?

Then create the final prompt.

⸻

Classroom Activity 3 – Prompt Battle

Give all students the same task:

“Create a study plan for Data Structures.”

Each student writes a prompt.

Generate the responses.

Then compare:

* Which prompt produced the most useful result?
* Which prompt was clearest?
* Which prompt contained unnecessary information?
* Which prompt controlled the output best?

The winning prompt should be selected based on output quality, not prompt length.

Best Practices

1. Start with the task

Know exactly what you want before writing the prompt.

⸻

2. Add only relevant context

Do not overload the AI with unnecessary information.

⸻

3. Use precise constraints

Instead of:

Make it short.

Use:

Keep the response below 300 words.

⸻

4. Specify the audience

For example:

Explain this to a beginner.

is usually better than providing no audience at all.

⸻

5. Specify output format when structure matters

For example:

Return the comparison as a markdown table.

⸻

6. Don’t force a role unnecessarily

Not every prompt needs:

“You are an expert…”

Use roles when they genuinely help establish perspective or style.

⸻

7. Don’t assume more words mean better prompts

The objective is clarity and relevance, not maximum prompt length.

⸻

8. Iterate

A prompt is rarely perfect on the first attempt.

Use:

Prompt
  ↓
Output
  ↓
Evaluate
  ↓
Identify Problem
  ↓
Refine Prompt
  ↓
New Output

⸻

Common Mistakes

Mistake	Better Approach
Vague task	Use a clear action verb
No audience	Specify the target audience when relevant
Too much irrelevant context	Include only useful information
No output structure	Specify format when needed
Excessive constraints	Add only constraints that matter
Always using elaborate roles	Use roles only when useful
Assuming long prompts are better	Focus on relevant information
One-shot thinking	Iterate and refine

⸻

Important Concept: Prompt ≠ Magic Formula

Students should not memorize RTCCO as a magic formula.

RTCCO is a thinking framework.

The goal is to ask:

What does the AI need to know to complete this task successfully?

Sometimes the answer may be:

Task + Output

Sometimes:

Role + Task + Context + Output

And for complex tasks:

Role + Task + Context + Constraints + Output

Summary

An effective prompt gives an AI model enough information to understand the user’s intention and produce a useful response. The RTCCO framework—Role, Task, Context, Constraints, and Output Format—provides a practical way to structure prompts.

However, RTCCO should not be treated as a rigid formula. Simple tasks often need only a few words, while complex tasks benefit from additional context, constraints, and output specifications. The objective of Prompt Engineering is not to create the longest possible prompt; it is to provide the right information, in the right way, for the task.
