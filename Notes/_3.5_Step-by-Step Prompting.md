# UNIT 3 – Prompt Engineering Techniques

# Topic 5: Step-by-Step Prompting

## Learning Objectives

After completing this topic, students will be able to:

* Define Step-by-Step Prompting.
* Understand why complex tasks can be divided into smaller steps.
* Create prompts that require a structured sequence of actions.
* Apply Step-by-Step Prompting to mathematics, study notes, coding, and analysis.
* Understand the limitations of this technique.

---

## 1. Definition

> **Step-by-Step Prompting is a prompting technique in which a task is divided into a sequence of clearly defined steps so that the AI follows a structured process to produce the required output.**

Instead of asking:

> "Solve this problem."

the prompt specifies the stages of the task.

### Basic Structure

```text
Task
 ↓
Step 1
 ↓
Step 2
 ↓
Step 3
 ↓
Final Output
```

---

## 2. Simple Analogy

Consider solving a mathematics problem.

A student normally follows:

```text
Understand the problem
        ↓
Identify given values
        ↓
Select formula
        ↓
Substitute values
        ↓
Calculate
        ↓
Final answer
```

A Step-by-Step Prompt follows a similar structured approach.

---

## 3. Basic Example

### Weak Prompt

```text
Find the time complexity of this algorithm.
```

### Step-by-Step Prompt

```text
Analyze the following algorithm.

Follow these steps:

1. Identify the number of iterations of each loop.
2. Determine how the loops interact.
3. Calculate the total number of operations.
4. Express the result using Big-O notation.
5. State the final time complexity.

Algorithm:
[CODE]
```

The second prompt provides a clear sequence for the task.

# 4. Step-by-Step Mathematics

```text
Solve the following equation.

Follow these steps:

1. Identify the equation.
2. Move constant terms to the appropriate side.
3. Simplify the equation.
4. Calculate the value of x.
5. State the final answer.

Equation:
3x + 6 = 15
```

Expected final answer:

```text
x = 3
```

# 5. Step-by-Step Problem Solving

```text
Solve the following problem.

Steps:
1. Identify the given information.
2. Identify what needs to be calculated.
3. Select the appropriate formula.
4. Substitute the values.
5. Calculate the result.
6. State the final answer with the correct unit.

Problem:
A car travels 120 km in 3 hours. Find its average speed.
```

# 6. Step-by-Step Study Notes

```text
Create study notes on Binary Search.

Follow these steps:

1. Give the definition.
2. Explain how the algorithm works.
3. Provide the algorithm steps.
4. Give a simple example.
5. State time complexity.
6. State space complexity.
7. Mention one practical application.
```

This produces a structured learning resource.

# 7. Step-by-Step Code Generation

```text
Create a C++ program to find the largest element in an array.

Follow these steps:

1. Understand the problem.
2. Identify the required input.
3. Design the algorithm.
4. Write the C++ code.
5. Explain the code.
6. Provide time and space complexity.
7. Test the code with a sample input.
```

This combines **code generation, explanation, and testing**.

# 12. Step-by-Step Prompt Components

A good Step-by-Step Prompt generally contains:

| Component     | Purpose                       |
| ------------- | ----------------------------- |
| Task          | Defines what needs to be done |
| Steps         | Defines the sequence          |
| Context       | Provides relevant information |
| Constraints   | Defines limitations           |
| Output Format | Defines final presentation    |

Example:

```text
Task + Steps + Context + Constraints + Output Format
```

---

# 13. Step-by-Step vs Zero-Shot

These are not necessarily competing techniques.

A prompt can be both:

> **Zero-Shot + Step-by-Step**

Example:

```text
Solve this problem step by step.
```

If no example is provided, it is **Zero-Shot**.

The phrase "step by step" describes the requested structure, not the number of examples.

---

# 14. Step-by-Step vs Few-Shot

Similarly, a prompt can combine:

> **Few-Shot + Step-by-Step**

For example:

```text
Example 1:
Problem → Step-by-step solution

Example 2:
Problem → Step-by-step solution

Now solve:
[NEW PROBLEM]
```

Here:

* Multiple examples → Few-Shot
* Structured solution → Step-by-Step

---

# 15. Advantages

* Breaks complex tasks into manageable stages.
* Makes the required process clearer.
* Produces more organized outputs.
* Useful for educational explanations.
* Useful for multi-stage tasks such as coding and analysis.
* Makes complex instructions easier to follow.

---

# 16. Limitations

* Long instructions can make the prompt unnecessarily complex.
* The AI may not always follow every step exactly.
* Incorrectly designed steps can lead to incorrect results.
* Some simple tasks do not require step-by-step instructions.
* For complex reasoning, the final output should still be checked for correctness.

---

# 17. Best Practices

### Do

* Divide complex tasks into logical steps.
* Keep steps clear and specific.
* Put steps in the correct order.
* Define the expected final output.
* Use constraints where necessary.
* Verify important results.

### Avoid

* Unnecessary steps.
* Repeated instructions.
* Contradictory steps.
* Extremely vague steps.
* Assuming that following steps guarantees a correct answer.

# 20. Practical Exercise

Create a prompt for:

> **Calculate the YoY growth of revenue.**

Use the following formula:

$$
YoY\ Growth =
\frac{Current\ Year\ Revenue - Previous\ Year\ Revenue}
{Previous\ Year\ Revenue}
\times 100
$$

The prompt should instruct the AI to:

1. Identify previous-year revenue.
2. Identify current-year revenue.
3. Calculate the difference.
4. Divide by previous-year revenue.
5. Multiply by 100.
6. State the final percentage.

# 22. Quick Revision

> **Step-by-Step Prompting = Divide the task into logical steps and clearly specify the sequence.**

```text
Complex Task
     ↓
Step 1
     ↓
Step 2
     ↓
Step 3
     ↓
Final Output
```

### Key Principle

> **For complex tasks, clearly defined steps can make the required process easier for the AI to follow and the output easier to evaluate.**
