UNIT 2 – Fundamental of Prompt Writing

Topic 2: Prompt Types

The syllabus covers the following prompt types:

1. Open-ended Prompt
2. Closed-ended Prompt
3. Instruction Prompt
4. Question Prompt
5. Persona Prompt

Important: These categories can overlap. A single prompt may be both a question prompt and a persona prompt, or an instruction prompt and a closed-ended prompt. These terms describe the purpose or structure of a prompt rather than mutually exclusive technical categories.

⸻

Learning Objectives

After completing this topic, students will be able to:

* Define different types of prompts.
* Distinguish between open-ended and closed-ended prompts.
* Understand instruction-based and question-based prompts.
* Understand persona prompts and when to use them.
* Identify the type of prompt used in a given situation.
* Convert one prompt type into another.
* Select an appropriate prompt type for a specific task.
* Combine multiple prompt types effectively.

⸻

1. Introduction

Not every interaction with AI has the same purpose.

Consider these five requests:

Explain Artificial Intelligence.

Is Python a programming language?

Summarize this article in 200 words.

What is the time complexity of Binary Search?

Act as a career counselor and review my resume.

All five are prompts, but they are designed differently.

This leads to the concept of:

Prompt Types

A prompt type refers to the way a prompt is designed based on the desired interaction or output.

⸻

2. Overview of Prompt Types

Prompt Type	Main Purpose	Typical Output
Open-ended	Explore ideas or generate creative responses	Multiple possibilities
Closed-ended	Obtain a specific answer	Short/direct answer
Instruction	Tell AI what action to perform	Task-specific output
Question	Ask for information or explanation	Answer/explanation
Persona	Establish a role or perspective	Role-oriented response

⸻

3. Open-Ended Prompts

Definition

An open-ended prompt allows the AI considerable freedom in constructing the response.

There is usually no single predetermined answer.

⸻

Example

What are some innovative ways to use AI in education?

There can be many valid answers.

The AI may discuss:

* Personalized learning
* AI tutors
* Automated feedback
* Question generation
* Accessibility
* Learning analytics
* Content creation

⸻

Characteristics

Open-ended prompts generally:

* Encourage exploration.
* Generate multiple ideas.
* Allow creative responses.
* Do not require one specific answer.
* Are useful for brainstorming.

⸻

Example: Brainstorming

Prompt

Suggest 15 innovative project ideas using Generative AI for college students.

Possible areas:

* Education
* Healthcare
* Agriculture
* Finance
* Environment
* Productivity

⸻

Example: Creative Writing

Write a short science-fiction story about a student who discovers an AI system that can predict future events.

The AI has significant creative freedom.

⸻

When Should You Use Open-Ended Prompts?

Use them when you want:

* Ideas
* Brainstorming
* Creativity
* Alternatives
* Discussion
* Exploration
* Multiple solutions

⸻

Advantages

* Encourages creativity.
* Useful for brainstorming.
* Can reveal unexpected ideas.
* Useful during the early stages of problem solving.

⸻

Limitations

The response may:

* Become too broad.
* Contain unnecessary information.
* Be difficult to evaluate objectively.
* Go in an unexpected direction.

⸻

4. Closed-Ended Prompts

Definition

A closed-ended prompt limits the possible response.

The expected answer is usually:

* Yes/No
* A specific value
* A selection
* A short factual response

⸻

Examples

Is Python an interpreted programming language?

Expected:

Yes, with important implementation nuances.

Another example:

What is 5 × 8?

Expected:

⸻

Example: Classification

Classify this customer feedback as Pricing, Support, or Features.

The model has only three allowed categories.

This is a closed-output task.

⸻

Example: Multiple Choice

Which data structure follows LIFO?

A. Queue
B. Stack
C. Linked List
D. Tree

Expected:

B. Stack

⸻

Open-Ended vs Closed-Ended

Feature	Open-Ended	Closed-Ended
Freedom	High	Limited
Answers	Many possible	Usually limited
Creativity	High	Low
Evaluation	More subjective	Easier
Example	“Suggest project ideas.”	“Is Python a programming language?”

⸻

5. Instruction Prompts

Definition

An instruction prompt explicitly tells the AI to perform an action.

The prompt usually contains an action verb.

Examples:

* Summarize
* Translate
* Rewrite
* Generate
* Classify
* Explain
* Compare
* Extract
* Convert
* Analyze

⸻

Examples

Summarize the following article in 200 words.

Convert these notes into a table.

Translate the following paragraph into Hindi.

Generate five interview questions for a Java developer.

Rewrite this email in a professional tone.

⸻

Why Instruction Prompts Are Important

Instruction prompting is one of the most fundamental ways of interacting with AI.

Instead of simply providing a topic:

Java

we provide an action:

Explain the concept of inheritance in Java using a simple example.

The AI now knows what operation it should perform.

⸻

Action Verb Technique

Students should identify the action verb in a prompt.

Example

Summarize this research paper in 300 words.

Action:

Summarize

⸻

Example

Compare Java and Python using a table.

Action:

Compare

⸻

Example

Rewrite this paragraph in simple English.

Action:

Rewrite

⸻

Instruction Prompt Template

[Action] + [Content/Subject] + [Requirements]

Example:

Summarize the following article in 250 words
using simple English and three bullet points.

⸻

6. Question Prompts

Definition

A question prompt asks the AI a question to obtain information, explanation, reasoning, or clarification.

Examples:

What is Machine Learning?

Why is recursion useful?

How does a compiler work?

What is the difference between TCP and UDP?

⸻

Types of Questions

Question prompts can ask:

What

What is Generative AI?

Why

Why is normalization used in databases?

How

How does Binary Search work?

When

When should we use a stack?

Where

Where is BFS used in real-world applications?

Who

Who developed the C programming language?

⸻

Question Prompt Example

Why is Binary Search faster than Linear Search for a sorted array?

This asks for an explanation rather than a simple fact.

⸻

Question Prompt vs Instruction Prompt

These can sometimes produce very similar results.

Question

What is polymorphism in Java?

Instruction

Explain polymorphism in Java with a simple example.

The first primarily asks for information.

The second explicitly tells the AI what to do.

⸻

7. Persona Prompts

Definition

A persona prompt instructs the AI to respond from a particular role, perspective, or professional style.

Examples:

Act as a university professor.

Act as a technical interviewer.

Act as a career counselor.

Act as a Python tutor.

Act as a product manager.

⸻

Why Use Persona Prompts?

A persona can help guide:

* Tone
* Perspective
* Vocabulary
* Depth
* Teaching style
* Type of recommendations

⸻

Example

Generic

Explain recursion.

Persona

Act as a Data Structures professor teaching first-year engineering students. Explain recursion using a simple real-world analogy.

The second prompt provides a more specific perspective.

⸻

Persona Prompt Structure

Act as a [ROLE/PERSONA].
[Perform the task]
[Additional context and constraints]

⸻

Example: Technical Interviewer

Act as a technical interviewer for an entry-level
software engineering position.
Ask me one Data Structures question at a time.
Wait for my answer before asking the next question.
After each answer:
1. Evaluate my response.
2. Identify mistakes.
3. Give a score out of 10.
4. Suggest how I could improve.

This is a strong persona-based prompt because it specifies:

* Role
* Task
* Interaction style
* Evaluation criteria

⸻

8. Persona Does Not Mean Pretending to Be a Real Person

Students should avoid thinking:

“If I tell AI to be Einstein, it literally becomes Einstein.”

Instead:

A persona is an instruction that guides the style, perspective, or behavior of the response.

For example:

Act as a patient mathematics tutor.

This helps establish a teaching style.

⸻

9. Combining Prompt Types

This is extremely important.

Prompt types are not mutually exclusive.

A single prompt can combine several types.

Example:

Act as a career counselor.                    ← Persona
Analyze my resume and suggest improvements.   ← Instruction
I am a final-year Computer Science student
looking for software internships.             ← Context
Give exactly 10 recommendations.              ← Constraint
Present them in a table.                      ← Output Format

This prompt contains:

* Persona
* Instruction
* Context
* Constraints
* Output Format

⸻

10. Open-Ended + Persona

Example:

Act as a startup mentor. Suggest innovative AI-based startup ideas for college students.

This is:

Persona + Open-ended

because many possible ideas can be generated.

⸻

11. Closed-Ended + Instruction

Example:

Classify the following customer feedback into exactly one of these categories: Pricing, Support, or Features.

This is:

Instruction + Closed-ended

because the AI must perform classification and choose from a limited set.

⸻

12. Question + Persona

Example:

Act as a history teacher. Why did the Industrial Revolution begin in Britain?

This is:

Question + Persona

⸻

13. Instruction + Output Control

Example:

Summarize the following article and return exactly five bullet points.

This is:

Instruction + Constraint + Output Format

⸻

14. Prompt Type Selection

Students can use this simple decision process:

What do I want from AI?
        │
        ├── Ideas / Creativity
        │       ↓
        │   Open-ended
        │
        ├── Specific answer
        │       ↓
        │   Closed-ended
        │
        ├── Perform an action
        │       ↓
        │   Instruction
        │
        ├── Ask for information
        │       ↓
        │   Question
        │
        └── Need a specific perspective?
                ↓
             Persona

Remember that multiple categories can apply simultaneously.

21. Choosing the Right Prompt Type

Situation	Recommended Type
Brainstorm ideas	Open-ended
Need a yes/no answer	Closed-ended
Need AI to perform a task	Instruction
Need information	Question
Need a specific perspective	Persona
Need expert-style evaluation	Persona + Instruction
Need classification	Instruction + Closed-ended
Need creative ideas from an expert perspective	Persona + Open-ended

⸻

22. Best Practices

1. Start with the desired outcome

Ask:

What exactly do I want AI to produce?

⸻

2. Use clear action verbs

Instead of:

Java inheritance.

Use:

Explain inheritance in Java.

⸻

3. Limit responses when necessary

For classification:

Choose exactly one category.

For multiple choice:

Return only A, B, C, or D.

⸻

4. Use persona only when useful

Do not unnecessarily add:

“Act as the world’s greatest expert…”

A simple role is often enough.

⸻

5. Combine prompt types when appropriate

Real-world prompts are often combinations.

⸻

6. Match the prompt type to the task

Don’t use an open-ended prompt when you require a precise classification.

⸻

7. Specify the desired level

For example:

Explain this to a beginner.

or

Provide a graduate-level technical explanation.

⸻

23. Common Mistakes

Mistake	Better Approach
Confusing topic with task	Use an action
Using open-ended prompts for fixed answers	Use constraints or closed outputs
Adding unnecessary persona	Use roles only when helpful
Asking vague questions	Be specific
Not defining classification categories	Provide allowed categories
Assuming prompt types are exclusive	Combine them when appropriate
Asking for “expert” answers without defining the task	Specify the desired outcome

Summary

Prompt types help us design AI interactions according to the desired outcome. Open-ended prompts are useful for creativity and exploration, while closed-ended prompts are useful when the possible responses need to be restricted. Instruction prompts tell AI what action to perform, question prompts ask for information or explanations, and persona prompts establish a particular perspective or role.

In real-world Prompt Engineering, these categories frequently overlap. A strong prompt might combine a persona, instruction, context, constraints, and output requirements. Therefore, students should focus less on memorizing labels and more on understanding what kind of interaction the task requires.
