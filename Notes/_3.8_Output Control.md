# UNIT 3 – Prompt Engineering Techniques

# Topic 8: Output Control

## Learning Objectives

After completing this topic, students will be able to:

* Define Output Control in Prompt Engineering.
* Understand why output format should be specified.
* Use prompts to generate **JSON, tables, bullet points, and structured outputs**.
* Select an appropriate output format for a given task.
* Combine Output Control with other prompting techniques.

---

## 1. Definition

> **Output Control is the technique of specifying how the AI should structure and present its response.**

Instead of only telling AI **what to do**, we also tell it **how the result should be presented**.

### Basic Idea

```text
Task → What should AI do?
Output Control → How should AI present the result?
```

For example:

```text
Explain Machine Learning.
```

can be changed to:

```text
Explain Machine Learning in a table with columns:
Concept | Explanation | Example
```

---

# 2. Why Output Control Is Important

The same information can be presented in different formats.

For example:

### Paragraph

Useful for detailed explanations.

### Bullet Points

Useful for quick revision.

### Table

Useful for comparison.

### JSON

Useful when the output needs to be processed by software.

Therefore:

> **The output format should match the purpose of the task.**

# 4. JSON Output

## Definition

> **JSON (JavaScript Object Notation) is a structured text format commonly used to represent data using key-value pairs and arrays.**

### Example Prompt

```text
Provide information about a student.

Return the output only as valid JSON with these fields:
name
enrollment_number
course
semester
```

Expected structure:

```json
{
  "name": "Rahul Sharma",
  "enrollment_number": "12345",
  "course": "B.Tech IT",
  "semester": 5
}
```

---

## 5. JSON with Multiple Records

```text
Generate information for three programming languages.

Return valid JSON using this structure:

{
  "languages": [
    {
      "name": "",
      "paradigm": "",
      "use": ""
    }
  ]
}
```

Possible output:

```json
{
  "languages": [
    {
      "name": "Java",
      "paradigm": "Object-Oriented",
      "use": "Enterprise applications"
    },
    {
      "name": "C++",
      "paradigm": "Multi-paradigm",
      "use": "System and application development"
    },
    {
      "name": "Python",
      "paradigm": "Multi-paradigm",
      "use": "Data Science and AI"
    }
  ]
}
```

# 6. Table Output

Tables are useful for **comparison and organized information**.

### Prompt

```text
Compare Machine Learning, Deep Learning, and Generative AI.

Present the answer in a table with these columns:

Technology | Definition | Example | Common Application
```

Expected structure:

| Technology       | Definition                           | Example           | Common Application |
| ---------------- | ------------------------------------ | ----------------- | ------------------ |
| Machine Learning | Learning patterns from data          | Spam detection    | Prediction         |
| Deep Learning    | ML using multi-layer neural networks | Image recognition | Computer Vision    |
| Generative AI    | Generates new content                | Text generation   | Content Creation   |

---

# 7. Bullet-Point Output

Bullet points are useful for **quick learning and revision**.

### Prompt

```text
Explain the advantages of Generative AI.

Return exactly 5 bullet points.
Keep each point within 20 words.
```

Expected format:

* Automates content creation.
* Helps summarize large amounts of information.
* Supports software development.
* Assists with idea generation.
* Improves productivity in many tasks.

---

# 8. Structured Output

Structured output means organizing information according to a predefined structure.

### Example

```text
Create study notes on Binary Search using exactly this structure:

1. Definition
2. Working
3. Algorithm
4. Example
5. Time Complexity
6. Space Complexity
7. Applications
```

The AI should organize the response according to the specified structure.

# 10. Output Control with Numbered Steps

Use exactly this structure:

# 11. Output Control with Word Limit

```text
Explain Generative AI in exactly 100 words.
```

or:

```text
Summarize the following text in approximately 150 words.
```

A word-count instruction provides a length constraint, although AI-generated word counts may not always be exact.

# 15. Output Control for Code

Output control can also be used for programming tasks.

```text
Write a C++ program to find the largest number in an array.

Return the answer in this order:

1. Approach
2. Algorithm
3. C++ Code
4. Sample Input
5. Sample Output
6. Time Complexity
7. Space Complexity
```

This prevents important sections from being omitted.

---

# 16. Output Control for Mathematics

```text
Solve the following problem.

Use this structure:

Given:
Formula:
Substitution:
Calculation:
Final Answer:
```

This produces a consistent mathematical solution format.

# 18. Combining Output Control with RTCCO

Output Control is part of the standard prompt structure learned earlier.

```text
ROLE:
Act as a Data Structures instructor.

TASK:
Explain Binary Search.

CONTEXT:
The audience is undergraduate IT students.

CONSTRAINTS:
Use simple language and one example.

OUTPUT FORMAT:
Definition → Working → Example → Complexity
```

Here, **Output Format** controls how the final answer is presented.

# 19. Choosing the Right Output Format

| Requirement              | Suitable Format                        |
| ------------------------ | -------------------------------------- |
| Quick revision           | Bullet Points                          |
| Comparison               | Table                                  |
| Software/data processing | JSON                                   |
| Procedure                | Numbered Steps                         |
| Study notes              | Structured Sections                    |
| Mathematical solution    | Given → Formula → Calculation → Answer |
| Code explanation         | Approach → Code → Example → Complexity |

# 20. Poor vs Good Output Control

### Poor Prompt

```text
Explain Java and C++.
```

The output format is unspecified.

### Better Prompt

```text
Compare Java and C++.

Use a table with these columns:

Feature | Java | C++
```

The second prompt provides clear output requirements.

---

# 21. Output Control Does Not Control Accuracy

An important principle:

> **Output Control controls presentation, not correctness.**

For example:

```text
Return the answer as JSON.
```

does not guarantee that the information inside the JSON is correct.

Therefore, important information should still be verified.

---

# 22. Best Practices

### Do

* Clearly specify the required format.
* Use an appropriate format for the task.
* Define required fields or columns.
* Specify the number of items when necessary.
* Define length constraints when required.
* Use consistent structures for repeated tasks.

### Avoid

* Giving contradictory format instructions.
* Using unnecessarily complicated formats.
* Requesting JSON when a simple answer is sufficient.
* Assuming a specific format guarantees factual accuracy.
