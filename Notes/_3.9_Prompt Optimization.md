### Learning Objectives

* Apply prompt optimization using **Role, Task, Context, Constraints, and Output Format**.

---

## 1. What is Prompt Optimization?

**Prompt Optimization** is the process of **improving a prompt so that the AI produces a more accurate, relevant, clear, and useful response.**

A prompt may work, but it can often be improved by adding the right:

* Role
* Task
* Context
* Constraints
* Output Format
* Examples, when required

### Simple Idea

> **Poor Prompt → Analyze Problem → Improve Prompt → Test → Refine**

### Analogy

Writing a prompt is like giving instructions to a student.

If you say:

> "Prepare notes on DSA."

The student may not know:

* Which topic?
* For which class?
* How detailed?
* What format?
* How many examples?

A better instruction produces a better result.

## 2. Example of Prompt Optimization

### Initial Prompt

```text
Explain Data Structures.
```

This prompt is too general.

### Optimized Prompt

```text
Act as a Data Structures instructor.

Explain "Stack" to second-year engineering students.

Include:
1. Definition
2. LIFO concept
3. Basic operations
4. Real-world example
5. One simple C++ example

Use simple language and headings.
Keep the explanation within 500 words.
```

### Improvement

The optimized prompt clearly specifies:

| Component     | Specification                       |
| ------------- | ----------------------------------- |
| Role          | Data Structures instructor          |
| Task          | Explain Stack                       |
| Context       | Second-year engineering students    |
| Constraints   | Simple language, 500 words          |
| Output Format | Headings and structured explanation |

## 3. Steps of Prompt Optimization

### Step 1: Identify the Goal

Clearly determine what you want the AI to produce.

**Weak:**

```text
Tell me about AI.
```

**Better:**

```text
Explain Generative AI for first-year engineering students.
```

---

### Step 2: Add Relevant Context

Provide information that helps AI understand the situation.

```text
Explain Generative AI for first-year engineering students
who have basic knowledge of Artificial Intelligence.
```

---

### Step 3: Define Constraints

Specify limitations or requirements.

```text
Use simple language.
Keep the explanation within 400 words.
Include two real-world examples.
```

---

### Step 4: Specify Output Format

Tell AI how the answer should be presented.

```text
Present the answer using:
- Headings
- Bullet points
- Examples
```

---

### Step 5: Review the Response

Check whether the generated response:

* Answers the actual task
* Contains the required information
* Follows the specified format
* Uses the appropriate level of detail
* Meets the constraints

---

### Step 6: Refine the Prompt

If the response is not satisfactory, modify the prompt.

```text
Original Prompt
      ↓
AI Response
      ↓
Identify Problems
      ↓
Modify Prompt
      ↓
Generate Again
      ↓
Evaluate Result
```

## 4. Before and After Optimization

### Before

```text
Create a study plan for DAA.
```

### After

```text
Act as a DAA instructor.

Create a 7-day study plan for a third-year engineering
student preparing for a DAA examination.

Topics:
- Asymptotic Analysis
- Recurrence Relations
- Divide and Conquer
- Greedy Algorithms
- Sorting

Allocate 2 hours per day.

For each day, provide:
1. Topic
2. Learning objective
3. Study time
4. Practice activity

Present the plan in a table.
```

The second prompt provides much clearer instructions and therefore gives the AI less room for misunderstanding.

## 5. Prompt Optimization Using RTCCO

Prompt optimization can be performed using the **RTCCO structure**:

**R – Role**
**T – Task**
**C – Context**
**C – Constraints**
**O – Output Format**

### Template

```text
Role:
[Define the role]

Task:
[Clearly describe the task]

Context:
[Provide relevant background information]

Constraints:
[Specify limitations and requirements]

Output Format:
[Specify the required format]
```

---

## 6. Common Prompt Optimization Problems

| Problem                          | Optimization                        |
| -------------------------------- | ----------------------------------- |
| Task is unclear                  | Clearly define the task             |
| Response is too general          | Add context                         |
| Response is too long             | Add length constraint               |
| Important information is missing | Specify required points             |
| Wrong audience level             | Define target audience              |
| Poorly organized response        | Specify output format               |
| Response style is unsuitable     | Define role/persona                 |
| Results are inconsistent         | Provide clear requirements/examples |

---

## 7. Best Practices

* Clearly define the **main objective**.
* Provide only **relevant context**.
* Use specific instructions instead of vague statements.
* Specify important constraints.
* Define the required output format.
* Review the generated response.
* Refine the prompt when the output does not meet the requirements.
* Avoid adding unnecessary information.

## Quick Revision

* **Prompt Optimization** = improving a prompt to get better AI output.
* Identify the goal first.
* Add relevant context.
* Define constraints.
* Specify output format.
* Review the response.
* Refine the prompt when necessary.
* **RTCCO** provides a useful structure for prompt optimization.

**Flow:**
**Create → Generate → Review → Optimize → Regenerate → Finalize**
