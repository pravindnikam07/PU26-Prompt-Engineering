## Learning Objectives

After completing this topic, students will be able to:

* Identify the components of a reusable prompt template.

# 1. Introduction

Imagine a teacher has to create a question paper for five different subjects.

Without a template, the teacher may write everything from scratch each time.

With a template, the teacher can create a standard structure and change only the subject-specific information.

The same idea applies to Prompt Engineering.

Instead of writing a completely new prompt every time, we can create a:

> **Prompt Template**

A prompt template is a **reusable prompt structure containing fixed instructions and changeable placeholders**.

---

# 2. Prompt vs Prompt Template

### Prompt

A specific instruction given to an AI for one particular task.

Example:

> Create 10 MCQs on Operating Systems for second-year engineering students.

---

### Prompt Template

A reusable structure:

> Create `[NUMBER]` MCQs on `[TOPIC]` for `[AUDIENCE]`. Include `[DIFFICULTY]` level questions and provide the answers in `[FORMAT]`.

Now the same template can be used for:

* Operating Systems
* Data Structures
* Java
* Computer Networks
* Database Management Systems

---

# 3. Simple Analogy

Think of a **form**.

A college form may contain:

```text
Name: __________
Enrollment No.: __________
Course: __________
Semester: __________
```

The structure remains the same.

Only the values change.

A prompt template works similarly:

```text
Topic: __________
Audience: __________
Task: __________
Format: __________
```

The structure stays fixed while the information changes.

---

# 4. Basic Prompt Template Structure

A useful general template is:

```text
Role:
[WHO should the AI act as?]

Task:
[WHAT should the AI do?]

Context:
[WHAT background information is relevant?]

Constraints:
[WHAT rules or limitations should be followed?]

Output Format:
[HOW should the response be presented?]
```

This is based on the **RTCCO framework** studied earlier.

---

# 5. Placeholder

A **placeholder** represents information that can be changed.

Common notation:

```text
[TOPIC]
[NUMBER]
[AUDIENCE]
[LANGUAGE]
[DIFFICULTY]
[FORMAT]
```

For example:

```text
Explain [TOPIC] to [AUDIENCE] using [NUMBER]
examples in [LANGUAGE].
```

We can replace:

```text
[TOPIC]      → Recursion
[AUDIENCE]   → First-year students
[NUMBER]     → 3
[LANGUAGE]   → Simple English
```

Result:

> Explain recursion to first-year students using 3 examples in simple English.

---

# 6. Why Use Prompt Templates?

Prompt templates provide several advantages.

### 1. Reusability

Write once and reuse multiple times.

### 2. Consistency

Similar tasks receive similar instructions.

### 3. Speed

Less time is spent rewriting prompts.

### 4. Standardization

Teams can use a common prompting structure.

### 5. Easy Modification

Only the required variables need to be changed.

### 6. Better Prompt Quality

A well-designed template helps users remember important instructions.

# 21. Fixed vs Variable Parts

A good prompt template contains two types of information.

## Fixed Components

These usually remain unchanged.

Example:

> Act as an experienced academic instructor.

> Do not invent information.

> Explain concepts clearly.

---

## Variable Components

These change depending on the task.

Example:

```text
[SUBJECT]
[TOPIC]
[AUDIENCE]
[DIFFICULTY]
[WORD COUNT]
```

# 22. Template Design

Think of a template as:

```text
                 PROMPT TEMPLATE
                       │
          ┌────────────┴────────────┐
          │                         │
       FIXED PART               VARIABLE PART
          │                         │
   Instructions                [TOPIC]
   Rules                       [AUDIENCE]
   Format                      [TASK]
   Quality criteria            [NUMBER]
          │                         │
          └────────────┬────────────┘
                       ↓
                FINAL PROMPT
```

---

# 23. Poor Template vs Good Template

## Poor Template

```text
Write about [TOPIC].
```

This is technically reusable but provides very little control.

---

## Better Template

```text
Act as a subject-matter instructor.

Explain [TOPIC] to [AUDIENCE].

Requirements:
- Use simple language.
- Include [NUMBER] examples.
- Explain important terminology.
- Mention common mistakes.

Output Format:
1. Definition
2. Explanation
3. Examples
4. Common Mistakes
5. Summary
```

The second template is more useful because it captures the requirements that should remain consistent.

---

# 24. Template Quality Checklist

Before creating a reusable prompt template, ask:

### 1. Is the task clearly defined?

### 2. Which information will change?

### 3. Which instructions should remain fixed?

### 4. Are the placeholders clearly named?

### 5. Are the constraints necessary?

### 6. Is the output format appropriate?

### 7. Can another person use the template without additional explanation?

That last question is particularly important.

> **A good template should be understandable even to someone who did not create it.**

# 27. Prompt Template vs Copy-Paste Prompt

A template is useful when the **task repeats**.

For example:

A student asks AI once:

> Explain recursion.

A template is unnecessary.

But if a teacher needs to create notes for:

* Unit 1
* Unit 2
* Unit 3
* Unit 4
* Unit 5

a study-notes template can save considerable time.

---

# 28. Template Iteration

A template should not be considered permanently perfect.

Use:

```text
Template
   ↓
Use
   ↓
Evaluate Output
   ↓
Identify Problems
   ↓
Improve Template
   ↓
Reuse
```

For example, if generated notes repeatedly lack examples, add:

> "Include at least two worked examples."

The template becomes better over time.

---

# 29. Important Best Practice: Don't Over-Template

Templates are useful, but excessive structure can become counterproductive.

For a simple request:

> Convert 10 USD to INR.

A huge template such as:

```text
Role:
Context:
Background:
Constraints:
Output:
Evaluation:
...
```

is unnecessary.

### Principle

> **Use the simplest template that reliably produces the required result.**

# 34. Best Practices for Students

### Do

* Use meaningful placeholders.
* Keep reusable instructions fixed.
* Make variable fields obvious.
* Keep templates easy to understand.
* Test templates with different inputs.
* Refine templates based on results.
* Maintain a personal prompt library.

### Don't

* Create unnecessarily complicated templates.
* Add irrelevant information.
* Use ambiguous placeholders.
* Assume one template works perfectly for every situation.
* Copy templates without understanding them.
* Treat templates as magic formulas.

---

# 35. Common Mistakes

| Mistake                             | Better Approach                   |
| ----------------------------------- | --------------------------------- |
| No placeholders                     | Identify changing information     |
| Too many placeholders               | Keep only necessary variables     |
| Unclear variable names              | Use `[TOPIC]`, `[AUDIENCE]`, etc. |
| No output structure                 | Define expected format            |
| Template is too long                | Remove unnecessary instructions   |
| Template only works for one example | Test multiple inputs              |
| Never improving the template        | Iterate based on output quality   |

# Quick Revision

## Prompt

A specific instruction for a particular task.

## Prompt Template

A reusable prompt structure containing **fixed instructions + variable placeholders**.

### Basic Structure

```text
Fixed Instructions
       +
[VARIABLES]
       ↓
Reusable Prompt
```

### Example

```text
Explain [TOPIC] to [AUDIENCE] using [NUMBER]
examples. Keep the explanation below [WORD LIMIT]
words and present it using [FORMAT].
```

---

# Summary

A **prompt template** is a reusable structure that helps users perform similar AI tasks consistently and efficiently. Templates contain fixed instructions that remain stable and placeholders that can be replaced with task-specific information.

A well-designed template improves **reusability, consistency, speed, and standardization**. However, templates should not become unnecessarily complicated. The best template is one that contains enough information to reliably produce the desired output while remaining easy to understand and modify.

Students should begin building their own **Prompt Library** during this course. Over time, this library can become a practical collection of reusable prompts for education, programming, career development, communication, research, and productivity.

> **Don't just collect prompts. Build reusable systems for solving recurring problems.**
