# Unit 3: Prompt Engineering Techniques

## Topic 11: Creating Prompt for Architecture

### Learning Objectives

After studying this topic, students will be able to:

- Understand how prompt engineering can be used for **architecture-related tasks**.
- Identify the important requirements in an architecture prompt.
- Create an architecture prompt using **RTCCO**.
- Generate structured architectural concepts using appropriate constraints and output formats.

---

## 1. Architecture Prompt

An **Architecture Prompt** is a prompt used to instruct AI to generate or describe an architectural concept based on requirements such as:

- Building type
- Purpose
- Size
- Number of floors
- Rooms or spaces
- Design requirements
- Materials
- Constraints
- Output format

For example, AI can help generate a **conceptual building plan, design description, space requirements, or architectural ideas**.

---

## 2. Basic Architecture Prompt

### Simple Prompt

```text
Design a house.
```

This prompt is too vague.

### Improved Prompt

```text
Design a conceptual 2-floor house for a family of four.

Include:
- 3 bedrooms
- Living room
- Kitchen
- 2 bathrooms
- Parking space

Provide a floor-wise description.
```

The second prompt gives AI specific requirements to work with.

---

## 3. Architecture Prompt Using RTCCO

### Role

```text
Act as an architectural design consultant.
```

### Task

```text
Create a conceptual design for a two-floor residential house.
```

### Context

```text
The house is intended for a family of four
on a 30 × 40 feet plot.
```

### Constraints

```text
Include three bedrooms, two bathrooms, a kitchen,
a living room and parking space.
Use the available space efficiently.
```

### Output Format

```text
Present the design floor-wise using headings and bullet points.
Include approximate space allocation for each area.
```

---

## 4. Complete Architecture Prompt

```text
Act as an architectural design consultant.

Create a conceptual design for a two-floor residential
house on a 30 × 40 feet plot for a family of four.

Requirements:
- 3 bedrooms
- 2 bathrooms
- 1 kitchen
- 1 living room
- 1 dining area
- Parking space
- Staircase connecting both floors

Use the available space efficiently.

Present the result using:
1. Ground Floor
2. First Floor
3. Space allocation
4. Design considerations

Use approximate dimensions where appropriate.
Clearly state that the design is conceptual.
```

## 5. Architecture Prompt for a Software System

The same prompting technique can be applied to **software architecture**.

### Example

```text
Act as a software architect.

Design a high-level architecture for an online
student management system.

The system should support:
- Student registration
- Student login
- Course management
- Attendance
- Examination results

Requirements:
- Web-based application
- Secure authentication
- Database support
- Separate student and administrator functions

Present the architecture using:
1. Components
2. Responsibilities
3. Data flow
4. Technology suggestions
```

This demonstrates that **architecture prompts are not limited to buildings**; they can also be used when designing software systems.

---

## Best Practices

- Clearly define the type of architecture.
- Provide dimensions or scale when relevant.
- Specify functional requirements.
- Clearly mention constraints.
- Specify the intended users or occupants.
- Ask for a structured output.
- Use **conceptual** designs for AI-generated architectural ideas.
- Professional architectural, structural, safety, and building-code requirements should be verified by qualified professionals before construction.
