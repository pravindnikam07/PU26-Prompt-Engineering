# Topic 7: Creating Prompts for Resume Writing

---

## Learning Objectives

After completing this topic, students will be able to:

* Understand how Prompt Engineering can assist with resume creation and improvement.
* Identify the important components of a resume-writing prompt.
* Create prompts for resume generation, review, and customization.
* Tailor a resume for a specific job description.
* Convert generic descriptions into stronger achievement-oriented statements.
* Use AI to identify missing skills and keywords.
* Improve resume structure, clarity, and consistency.
* Understand the limitations and risks of using AI for resumes.

---

# 1. Introduction

A **resume** is a concise document that presents a candidate's relevant:

* Education
* Skills
* Projects
* Experience
* Achievements
* Certifications
* Professional background

The purpose of a resume is not to describe everything about a person.

Its purpose is to communicate:

> **Why is this candidate relevant to this particular opportunity?**

AI can assist students with:

```text
Resume Creation
      ↓
Resume Review
      ↓
Job Description Analysis
      ↓
Keyword Identification
      ↓
Resume Customization
      ↓
Content Improvement
      ↓
Final Review
```

---

# 2. Why Prompt Engineering Matters for Resume Writing

Consider this prompt:

> Improve my resume.

The instruction is too broad.

AI does not know:

* Which job?
* Which industry?
* Which experience?
* What should be emphasized?
* What should be removed?
* What format is expected?
* What information must remain unchanged?

A better prompt provides this context.

---

# 3. Important Principle

> **Never ask AI to make a candidate look more qualified than they actually are.**

AI should improve the **presentation of real information**, not manufacture qualifications.

For example:

❌

> Add some impressive software-development experience to my resume.

Better:

> Rewrite my existing project experience to communicate its technical impact more clearly without adding experience that I do not have.

---

# 4. Basic Resume Prompt Structure

A useful resume prompt contains:

```text
ROLE
   ↓
TARGET JOB
   ↓
CANDIDATE PROFILE
   ↓
CURRENT RESUME
   ↓
JOB DESCRIPTION
   ↓
REQUIREMENTS
   ↓
CONSTRAINTS
   ↓
OUTPUT FORMAT
```

---

# 5. Component 1 – Role

Tell AI what perspective it should use.

Examples:

> Act as an experienced technical recruiter.

> Act as a professional resume writer specializing in entry-level software developers.

> Act as an HR specialist reviewing engineering resumes.

---

# 6. Component 2 – Target Role

A resume should normally be evaluated against a target opportunity.

Examples:

* Software Developer
* Data Analyst
* Frontend Developer
* Technical Trainer
* AI/ML Intern
* Cybersecurity Analyst

Compare:

> Review my resume.

with:

> Review my resume for an entry-level Software Developer position.

The second gives AI a clear evaluation target.

---

# 7. Component 3 – Candidate Profile

Provide relevant information.

Example:

```text id="2e1zq8"
Education:
B.Tech in Information Technology

Programming:
C++, Java, Python

Web Technologies:
HTML, CSS, JavaScript

Projects:
Student Management System
E-commerce Website

Experience:
Academic projects and internship experience
```

---

# 8. Component 4 – Job Description

A job description can provide valuable context.

Example:

```text id="q0p3u7"
Job Title:
Software Developer Intern

Required Skills:
- Java
- SQL
- Git
- REST APIs

Preferred:
- Spring Boot
- React
```

AI can compare this against the candidate's actual background.

---

# 9. Component 5 – Constraints

Useful constraints include:

> Do not invent experience.

> Do not add skills that are not present.

> Preserve factual information.

> Do not exaggerate achievements.

> Keep the resume to one page.

> Use concise bullet points.

---

# 10. Component 6 – Output Format

For example:

```text id="v3g5kl"
Output:
1. Overall Assessment
2. Strengths
3. Missing Keywords
4. Weak Sections
5. Recommended Changes
6. Improved Content
7. Final Checklist
```

A structured output makes the result easier to review.

# 11. Basic Resume Review Prompt

```text id="6y7q9d"

- Identify specific weaknesses.
- Suggest practical improvements.
- Prioritize the most important changes.

Output:
1. Overall Assessment
2. Strengths
3. Weaknesses
4. Section-wise Recommendations
5. Priority Improvements

Resume:
"""

"""
```

# 12. Resume Creation Prompt

If a student has information but no resume:

```text id="q2x4k6"
Act as a professional resume writer.

Create a one-page resume for an entry-level
[JOB ROLE] candidate.

Candidate Information:
Name: [NAME]
Education: [EDUCATION]
Skills: [SKILLS]
Projects: [PROJECTS]
Experience: [EXPERIENCE]
Certifications: [CERTIFICATIONS]
Achievements: [ACHIEVEMENTS]

Requirements:
- Use concise professional language.
- Prioritize information relevant to the target role.
- Do not invent qualifications or experience.
- Use strong action verbs where appropriate.
- Keep the content suitable for a one-page resume.

Output:
1. Professional Summary
2. Technical Skills
3. Projects
4. Education
5. Experience
6. Certifications/Achievements
```

# 13. Resume Summary Prompt

A professional summary should communicate the candidate's relevant profile quickly.

```text id="n8y2c4"
Write a concise professional summary for an entry-level
Software Developer.

Candidate:
- B.Tech IT student
- Strong foundation in C++ and Java
- Experience developing academic web projects
- Interested in backend development

Requirements:
- 3–4 sentences.
- Professional tone.
- Do not exaggerate experience.
- Focus on skills relevant to software development.
```

---

# 14. Weak vs Strong Summary

### Weak

> I am a hardworking student looking for a good job where I can use my skills and grow.

Problems:

* Generic
* No technical identity
* No specialization
* No evidence

### Better

> B.Tech IT student with a strong foundation in C++ and Java and hands-on experience developing academic software projects. Interested in backend development and building practical software solutions. Seeking an entry-level opportunity to apply programming and problem-solving skills.

The second is more specific.

---

# 15. Project Description Prompt

Students often have technically good projects but describe them poorly.

### Weak

> Made a student management system using Java.

A better prompt:

```text id="w2j6q8"
Rewrite the following project description for a technical resume.

Project:
Student Management System

Technology:
Java, MySQL

Features:
- Student registration
- Attendance management
- Search functionality
- Database storage

Requirements:
- Use concise bullet points.
- Highlight technical implementation.
- Use strong action verbs.
- Do not invent features.
- Keep each bullet under approximately 20 words.
```

---

# 16. Action Verbs

Resume bullets often become stronger when they begin with meaningful action verbs.

Examples:

| Weak      | Better               |
| --------- | -------------------- |
| Made      | Developed            |
| Worked on | Implemented          |
| Helped    | Contributed to       |
| Used      | Utilized             |
| Did       | Executed             |
| Created   | Designed / Developed |
| Fixed     | Resolved             |
| Tested    | Validated            |

However:

> **Never choose an impressive verb if it misrepresents what the candidate actually did.**

---

# 17. Achievement-Oriented Writing

Compare:

### Weak

> Created a website using HTML and CSS.

### Better

> Developed a responsive website using HTML and CSS with structured navigation and reusable page components.

Only use claims that are actually true.

---

# 18. Quantification

Numbers can make achievements clearer when they are genuine.

Example:

> Developed a website with 8 responsive pages.

or:

> Automated processing of 200+ certificate records.

But students must never invent numbers merely to make the resume look impressive.

### Rule

> **Use real measurable evidence, not manufactured metrics.**

---

# 19. Resume Bullet Improvement Prompt

```text id="7u4w9e"
Improve the following resume bullet.

Original:
"[BULLET]"

Requirements:
- Preserve the original meaning.
- Make the contribution clearer.
- Use a strong but accurate action verb.
- Add measurable impact only if it is already supported by the information.
- Keep it concise.
- Do not invent results.
```

# 20. Skills Section Prompt

```text id="g6k8m1"
Organize the following skills into a professional technical
skills section for a Software Developer resume.

Skills:
C++, Java, Python, HTML, CSS, JavaScript, Git, MySQL

Requirements:
- Group related technologies.
- Do not add skills that are not listed.
- Avoid unnecessary descriptions.
```

Possible organization:

```text

Web: HTML, CSS, JavaScript

Tools: Git
```

# 21. Job Description Analysis

One of the most useful applications of Prompt Engineering is comparing a resume against a job description.

### Prompt

```text id="x8v2n5"
Act as a technical recruiter.

Analyze the following job description.

Identify:
1. Required technical skills
2. Preferred technical skills
3. Soft skills
4. Responsibilities
5. Important domain knowledge
6. Potential resume keywords

Do not recommend adding a skill unless the candidate actually
has it.

Job Description:
"""
[JOB DESCRIPTION]
"""
```

# 22. Resume vs Job Description

Once the job description has been analyzed:

```text id="r4k9z2"
Compare my resume with the job description.

Identify:

| Requirement | Present in Resume? | Evidence | Recommendation |
|---|---|---|---|

Do not suggest adding qualifications I do not have.

Resume:
"""
[RESUME]
"""

Job Description:
"""
[JOB DESCRIPTION]
"""
```

This produces a more useful gap analysis.

---

# 23. Skills Gap Analysis

AI can categorize skills into:

```text id="n7c3m6"
        Job Requirements
               │
       ┌───────┼────────┐
       ↓       ↓        ↓
   Already   Missing   Related
   Have      Skills    Skills
```

For example:

| Job Requirement | Candidate |
| --------------- | --------- |
| Java            | Have      |
| SQL             | Have      |
| Spring Boot     | Learning  |
| React           | Missing   |
| Git             | Have      |

This can help students plan learning.

---

# 24. Important Ethical Rule

A resume should not claim:

> "Experienced in Spring Boot"

if the student has only watched a tutorial.

Instead:

> "Currently learning Spring Boot"

if that is accurate.

AI should help students present **truthful information clearly**.

# 25. Resume Customization

A single resume may not be equally relevant to every job.

For example:

### Job A

Frontend Developer

Important:

* HTML
* CSS
* JavaScript
* React

### Job B

Backend Developer

Important:

* Java
* Spring Boot
* SQL
* REST APIs

The candidate's actual experience may be the same, but the **emphasis** can change.

---

# 26. Resume Customization Prompt

```text id="t6r4k1"
Act as a technical recruiter.

Customize my resume for the following job description.

Rules:
- Use only information already present in my resume.
- Prioritize experiences and skills relevant to the job.
- Reorder information where appropriate.
- Rewrite bullets for clarity and relevance.
- Do not invent experience, skills, metrics, or qualifications.

Output:
1. Recommended Summary
2. Relevant Skills
3. Priority Projects
4. Improved Bullet Points
5. Missing Requirements
6. Final Recommendations

Resume:
"""
[RESUME]
"""

Job Description:
"""
[JOB DESCRIPTION]
"""
```

# 27. Resume Formatting Prompt

AI can also help identify formatting inconsistencies.

```text id="x7c4n9"
Review the following resume for consistency.

Check:
- Heading style
- Date format
- Bullet style
- Capitalization
- Spacing
- Section order
- Verb tense
- Punctuation

Do not rewrite the content yet.

Output:
Issue | Location | Recommendation
```

This separates **content review** from **format review**.

# 28. Resume Grammar and Language Review

```text id="b5v8k2"
Proofread my resume.

Check:
- Grammar
- Spelling
- Word choice
- Verb tense
- Sentence consistency
- Unnecessary repetition

Requirements:
- Preserve factual information.
- Do not add achievements.
- Do not change technical terminology unnecessarily.

Return:
Original → Suggested → Reason
```

# 29. Resume ATS Discussion

Many organizations use software to help process large numbers of applications.

Students often hear the term:

> **ATS – Applicant Tracking System**

AI can help make resume content more clearly aligned with a job description.

However, students should avoid treating ATS optimization as a guarantee of selection.

### Better principle:

> **Use relevant terminology naturally and truthfully rather than stuffing keywords.**

---

# 30. Keyword Stuffing – What Not to Do

Suppose a job description repeatedly mentions Java.

Bad approach:

> Java Java Java Java Java Java Java...

This is not professional.

Better:

> Developed backend functionality using Java and implemented database operations using SQL.

The keyword appears naturally because it describes actual experience.

---

# 31. Resume Review with Priorities

Instead of asking AI to list 50 problems, ask it to prioritize.

```text id="q1m6v8"
Review my resume and identify the five most important changes
that would improve its relevance for the target role.

Rank each issue as:
High
Medium
Low

For each issue explain:
- Problem
- Why it matters
- Recommended action
```

This helps students focus on high-impact improvements.

* What was the student's role?

# 37. Classroom Activity – Job Description Detective

Give students a job description.

Ask them to identify manually:

1. Technical skills
2. Soft skills
3. Responsibilities
4. Experience requirements
5. Education requirements

Then ask AI to perform the same analysis.

### Discussion

> Did AI identify the same requirements?

This teaches students to use AI as an **assistant rather than an unquestioned authority**.

---

# 38. Classroom Activity – Resume A/B Testing

Create:

### Resume A

Generic resume.

### Resume B

Customized for a specific job.

Ask AI to evaluate both against the same job description.

Use:

| Criterion         | Resume A | Resume B |
| ----------------- | -------: | -------: |
| Relevance         |       /5 |       /5 |
| Skill Alignment   |       /5 |       /5 |
| Clarity           |       /5 |       /5 |
| Project Relevance |       /5 |       /5 |
| Overall Fit       |       /5 |       /5 |

Then discuss why Resume B may perform better.

# 41. Best Practices

### Do

* Target the resume toward a specific role.
* Use actual job descriptions.
* Provide real candidate information.
* Ask AI to identify gaps.
* Highlight relevant projects.
* Use concise bullet points.
* Quantify achievements only when accurate.
* Use keywords naturally.
* Verify every claim.
* Maintain your own judgment.

### Don't

* Invent skills.
* Invent experience.
* Invent metrics.
* Fake certifications.
* Claim proficiency you don't have.
* Stuff keywords.
* Copy AI-generated content without reviewing it.
* Include confidential information unnecessarily.

| ---------------------------- | ----------------------------------- |

| Generic resume for every job | Customize relevant sections         |

| Long paragraphs              | Use concise bullets                 |
| Generic summary              | Target the desired role             |
| No project details           | Explain contribution and technology |

# Summary

Prompt Engineering can significantly improve the process of creating and refining resumes. A strong resume prompt provides the **target role, candidate information, job description, evaluation criteria, constraints, and desired output structure**.

One of the most valuable applications is **resume-to-job-description comparison**. AI can help identify relevant skills, missing requirements, weak project descriptions, and areas where the resume could be more clearly aligned with a specific opportunity.

However, students must maintain strict accuracy. AI should **never be used to fabricate experience, skills, certifications, achievements, metrics, or qualifications**. The best approach is to use AI to communicate genuine experience more clearly and strategically.

> **A strong AI-assisted resume does not make you look like someone else. It makes your real strengths easier for the right employer to recognize.**
