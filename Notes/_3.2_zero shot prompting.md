# 1. Introduction

In Prompt Engineering, we often want an AI model to perform a task without showing it an example of the expected answer.

This technique is called:

> ## **Zero-Shot Prompting**

The term **"zero-shot"** means that we provide **zero examples** of the task in the prompt.

The AI receives an instruction and attempts to perform the task based on its existing capabilities and understanding.

---

# 2. Simple Definition

> **Zero-Shot Prompting is a technique in which an AI model is asked to perform a task without being given any examples of the desired input-output behavior.**

### Simple pattern

```text id="zq1v5m"
Instruction
     ↓
AI Model
     ↓
Output
```

There are **no examples** between the instruction and the task.

---

# 3. Real-Life Analogy

Imagine a teacher tells a student:

> "Classify these animals as mammals, birds, or reptiles."

The teacher gives:

- No example
- No solved question

The student uses their existing knowledge to perform the task.

This is similar to Zero-Shot Prompting.

---

# 4. Zero-Shot vs Example-Based Prompting

### Zero-Shot

```text id="2t5q8c"
Classify the following review as Positive, Negative, or Neutral:

"The product arrived on time and works perfectly."
```

No examples are provided.

### One-Shot

```text id="9r4k1p"
Example:
Review: "Excellent product."
Classification: Positive

Now classify:
"The product arrived on time and works perfectly."
```

One example is provided.

### Few-Shot

Multiple examples are provided before the actual task.

---

# 5. Why Is It Called "Zero-Shot"?

The word **shot** refers to an example of the task being demonstrated.

Therefore:

| Technique | Number of examples |
| --------- | -----------------: |
| Zero-Shot |                  0 |
| One-Shot  |                  1 |
| Few-Shot  |     A small number |
| Many-Shot |      Many examples |

In this topic, our focus is **Zero-Shot Prompting**.

---

# 6. Basic Zero-Shot Prompt

```text id="5u2w8r"
Summarize the following paragraph in three bullet points:

[TEXT]
```

There is:

- No example summary
- No demonstration
- Only an instruction

Therefore, it is a zero-shot prompt.

# 7. Zero-Shot Classification

One of the most common applications is classification.

### Example

```text id="d7n4k2"

categories:

- Pricing
- Support
- Features

Feedback:
"The subscription is too expensive for my small business."
```

The AI must select the appropriate category without seeing examples.

Expected result:

> **Pricing**

```text id="m8c2q5"

```

This reduces ambiguity.

# 19. Zero-Shot Reasoning Instruction

A prompt can request a structured solution:

```text id="y3v7k5"
Solve the following problem.

Requirements:
1. Identify the given information.
2. State the relevant formula.
3. Substitute the values.
4. Calculate the result.
5. State the final answer clearly.

Problem:
Find the time complexity of:
for(int i = 0; i < n; i++)
    cout << i;
```

This remains zero-shot because **no example solution is provided**.

---

# 20. Zero-Shot vs "Step-by-Step"

Students may confuse these concepts.

They are different dimensions.

### Zero-Shot

Describes:

> **How many examples are provided?**

### Step-by-Step

Describes:

> **How the task is requested to be approached or presented.**

Therefore, a prompt can be:

> **Zero-shot + step-by-step**

Example:

```text id="r6p2v8"
Solve this problem step by step.
```

No example is provided.

---

# 21. Zero-Shot + Output Control

We can combine Zero-Shot Prompting with output constraints.

```text id="b9k5m3"
Classify each sentence as Positive, Negative, or Neutral.

Return only one label per sentence.

1. "The software works perfectly."
2. "The application keeps crashing."
3. "The update was released yesterday."
```

Expected format:

```text
Positive
Negative
Neutral
```

# 24. Zero-Shot + Context

```text id="v8q5r2"
You are analyzing feedback collected from users of a
college learning-management system.

Classify each feedback item into:
- Pricing
- Support
- Features

Use "Pricing" only for cost-related complaints,
"Support" for service/help-related problems,
and "Features" for requests or problems related to
functionality.

Feedback:
"""
[FEEDBACK]
"""
```

This is stronger because the categories are defined.

# 25. Defining Categories Clearly

Suppose the categories are:

```text id="x5j7p3"
Pricing
Support
Features
```

This may be ambiguous.

Instead:

```text id="q8n4m6"
Pricing = complaints or questions about cost, subscription,
fees, or billing.

Support = issues involving customer service, assistance,
response time, or technical support.

Features = requests or problems related to product
functionality or capabilities.
```

This can improve classification consistency.

# 26. Zero-Shot Classification with Three Categories

A useful practical example from the syllabus:

```text id="t7c3k9"
Act as a customer-feedback classification system.

Classify each feedback item into exactly one category:

1. Pricing – concerns about cost, fees, or billing.
2. Support – concerns about customer service or assistance.
3. Features – concerns about product functionality.

Rules:
- Select exactly one category.
- Do not create new categories.
- Provide a one-sentence reason.

Feedback:
"The new version is expensive, but I also like the new
dashboard."
```

The AI must determine the **primary issue**.

---

# 27. Handling Ambiguous Inputs

Suppose:

> "The software is expensive and the support team is slow."

This contains two issues.

A simple zero-shot prompt might produce inconsistent results.

Improve the instruction:

```text id="e9p5w4"
If multiple categories apply, select the category that
represents the primary complaint.

Do not return multiple categories.
```

This introduces a clear decision rule.

# 34. Advantages of Zero-Shot Prompting

### 1. Simple

It is easy to construct.

### 2. Fast

No examples need to be prepared.

### 3. Flexible

It can be applied to many tasks.

### 4. Useful for general tasks

Examples include:

- Summarization
- Translation
- Explanation
- Classification
- Rewriting
- Question generation
- Code generation

### 5. Less prompt overhead

The prompt can be relatively short when the task is straightforward.

---

# 35. Limitations of Zero-Shot Prompting

Zero-shot prompting is not always the best approach.

### 1. Ambiguous tasks

If the task is unclear, the output may vary.

### 2. Complex formatting

AI may not follow a very specific output pattern consistently.

### 3. Specialized classification

Without examples, subtle category distinctions may be difficult.

### 4. Unusual tasks

If the task requires a very specific transformation, examples may help.

### 5. Domain-specific expectations

The AI may not understand the exact pattern expected by the user.

---

# 36. When Should You Use Zero-Shot Prompting?

Use it when:

- The task is straightforward.
- Instructions are clear.
- The desired output is conventional.
- Examples are unnecessary.
- You want a quick result.
- The task can be described precisely.

Examples:

> Translate this sentence.

> Summarize this paragraph.

> Explain binary search.

> Classify the sentiment.

---

# 37. When Should You Avoid Zero-Shot Prompting?

Consider examples when:

- Output must follow a very specific pattern.
- The task is unusual.
- Categories are difficult to distinguish.
- The desired style is highly specific.
- The task has many exceptions.
- The model repeatedly produces inconsistent results.

This naturally leads to **One-Shot and Few-Shot Prompting**, which are the next techniques in the syllabus.

# 38. Zero-Shot Prompt Optimization

Suppose the prompt is:

> Classify these reviews.

The output may be inconsistent.

Improve it step by step.

### Version 1

> Classify these reviews.

### Version 2

> Classify each review as Positive, Negative, or Neutral.

### Version 3

> Classify each review as Positive, Negative, or Neutral. Return exactly one label per review.

### Version 4

```text id="r1d9m4"
Classify each review as exactly one of:

Positive – clearly favorable opinion.
Negative – clearly unfavorable opinion.
Neutral – factual or balanced statement without a clear opinion.

Return:
Review Number | Label | One-sentence reason
```

This demonstrates **prompt optimization without examples**.

# 46. Best Practices

### Do

- State the task clearly.
- Define categories when classifying.
- Explain ambiguous labels.
- Specify the desired output.
- Provide relevant context.
- Add decision rules for difficult classifications.
- Use constraints where necessary.
- Review the output.

### Don't

- Assume AI knows your exact interpretation.
- Use vague categories.
- Give contradictory instructions.
- Expect perfect results for complex tasks.
- Treat AI output as automatically correct.

---

# 47. Common Mistakes

| Mistake                       | Problem                     | Better Approach   |
| ----------------------------- | --------------------------- | ----------------- |
| "Classify this"               | No categories               | Define labels     |
| Unclear labels                | Inconsistent classification | Define each label |
| No output format              | Difficult to process        | Specify format    |
| Ambiguous input               | Multiple interpretations    | Add decision rule |
| Overly broad task             | Unfocused response          | Narrow the task   |
| No constraints                | Unexpected output           | Add requirements  |
| Complex task with no examples | Pattern may be unclear      | Consider few-shot |

# 53. Final Takeaway

The fundamental idea behind Zero-Shot Prompting is simple:

> **Tell the AI what you want without showing it an example.**

However, effective zero-shot prompting requires more than simply giving an instruction.

A strong zero-shot prompt should clearly communicate:

> **Task + Context + Constraints + Output Format**

And when classification is involved:

> **Categories + Category Definitions + Decision Rules**

### Golden Principle

> **If the task is simple and can be clearly described, try Zero-Shot Prompting first. If the model cannot reliably follow a specific pattern, consider providing examples through One-Shot or Few-Shot Prompting.**
